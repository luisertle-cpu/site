ℹ️ Como usar este site

Toque no botão "A+" no topo da página para aumentar o tamanho das letras, ou em "Alto contraste" para deixar as cores mais fortes e fáceis de enxergar.

Se você tem dificuldade para distinguir cores, toque em "Modo daltônico" — as cores da página mudam para tons mais fáceis de diferenciar, e cada remédio tomado também mostra um círculo preenchido, não só uma cor.

Se você prefere ouvir em vez de ler, toque em "Ouvir a página" e o computador ou celular vai ler todo o conteúdo em voz alta para você. Este site também funciona bem com leitores de tela, como o NVDA, o VoiceOver ou o TalkBack.

Para marcar um remédio como tomado, basta tocar no botão ao lado dele. Para ligar para alguém, toque no cartão da pessoa.
